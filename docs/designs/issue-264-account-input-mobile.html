Interaction decisions

  • Account names are searched case insensitively; only nonempty groups appear.
  • Selected values remain staged across searches in multiple mode.
  • Cancel, swipe dismissal, and the system back action leave the committed value intact.
  • Rows use radio semantics in single mode and checkbox semantics in multiple mode; the whole row is a touch target.
  • The sheet uses the app’s existing native BottomSheet integration and Luna Mobile theme tokens.
