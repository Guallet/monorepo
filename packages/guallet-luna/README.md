# Luna UI for Web

The web Luna UI package provides the controlled category icon set used by the
Guallet web application.

```tsx
import { CategoryIcon, MoneyIcon } from '@guallet/luna/icons';

<MoneyIcon />;
<CategoryIcon name="IconCash" />;
```

The React Native implementation lives in `packages/guallet-luna-rn` and is
aliased to the same `@guallet/luna` consumer import in the mobile app.
